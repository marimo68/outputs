# 開催レポートの追加方法

このブログは、外部サービスを使わずHTMLファイルを追加して更新する静的ブログです。

1. `post-template.html` を複製し、公開日と内容が分かる名前に変更します。
   - 例：`2026-09-20-report.html`
2. 複製した記事内のタイトル、説明文、日付、本文を編集します。
3. 公開する記事では、`<meta name="robots" content="noindex, nofollow">` と画面上部の `article-template-notice` を削除します。
4. 写真は `images/blog/` フォルダを作成して保存し、記事内の画像パスと代替テキストを変更します。
   - 例：`../images/blog/2026-09-20-main.jpg`
5. `blog/index.html` のコメント位置に、公開した記事へのリンクを追加します。
6. 必要に応じてトップページの開催レポートカードのリンクも、公開した記事へ変更します。

## 写真を掲載するときの注意

- 参加者が写る写真は、掲載許可を確認してから使用してください。
- 写真の内容が分かる短い代替テキストを `alt` 属性に入力してください。
- Web表示を軽くするため、横幅1600px程度・WebPまたはJPEG形式を推奨します。

## 更新する主なファイル

- `blog/index.html`：記事一覧
- `blog/日付-report.html`：個別記事
- `index.html`：トップページのブログ紹介
- `style.css`：全ページ共通のデザイン
- `script.js`：全ページ共通のナビゲーション動作
